## 📤 Upload to GitHub (Choose ONE method)

### Method 1: Create Repo First, Then Push (EASIEST)

#### Step 1: Create the Repository
1. Go to: https://github.com/new
2. Repository name: **portfolio** (or **srijan123-sys**)
3. Description: "Professional portfolio with 3D effects and glassmorphism design"
4. **IMPORTANT:** Keep it **PUBLIC** (for GitHub Pages)
5. **DO NOT** check "Add a README file"
6. **DO NOT** add .gitignore or license
7. Click **"Create repository"**

#### Step 2: Push Your Code
Open PowerShell/Terminal and run these commands:

```bash
cd "C:\Users\Srijan Pradhan\portfolio"

# Update the remote URL with YOUR repository name
git remote set-url origin https://github.com/srijan123-sys/portfolio.git

# Push to GitHub (you may need to authenticate)
git push -u origin main
```

If it asks for authentication:
- **Username:** Your GitHub username
- **Password:** Use a **Personal Access Token** (not your password)
  - Get token from: https://github.com/settings/tokens
  - Click "Generate new token (classic)"
  - Select "repo" scope
  - Copy the token and use it as password

## 🌐 Enable GitHub Pages (Make it Live!)

After uploading to GitHub:

1. Go to your repository: `https://github.com/srijan123-sys/portfolio`
2. Click **Settings** (top right)
3. Scroll down and click **Pages** (left sidebar)
4. Under **Source**, select:
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**
6. Wait 1-2 minutes

Your portfolio will be live at:
```
https://srijan123-sys.github.io/portfolio/
```

## ❓ Troubleshooting

### Can't push to GitHub?
- Make sure repository exists on GitHub first
- Use Personal Access Token instead of password
- Or use GitHub Desktop (easier)

### Repository not found?
- Check the repository name matches
- Make sure it's created on YOUR GitHub account
- URL should be: `https://github.com/YOUR-USERNAME/portfolio`

### Scrolling still laggy?
- Clear browser cache (Ctrl + Shift + Delete)
- Try different browser (Chrome recommended)
- Disable browser extensions
- Check browser console for errors (F12)

### GitHub Pages not working?
- Wait 2-3 minutes after enabling
- Check Settings → Pages for deployment status
- Make sure branch is set to **main**
- Repository must be **public**
